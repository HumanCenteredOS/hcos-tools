# HCOS™ Professional Prompts

HCOS™ Professional Prompts are reusable instructional resources that help
people apply the HCOS™ framework consistently within professional practice.

These prompts may support:

- workflow discovery
- evidence review
- systems analysis
- professional decision-making
- communication
- documentation
- human load assessment
- governance analysis
- instrument discovery
- organizational learning

Prompts support, but do not replace, professional judgment, organizational
policy, subject-matter expertise, or appropriate human review.
