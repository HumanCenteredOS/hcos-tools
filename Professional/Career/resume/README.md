# HCOS™ Professional Career Tools

This repository contains Human-Centered Operating Systems™ (HCOS™) tools that support career development through truthful, evidence-informed, and human-centered professional documentation.

The resources in this repository are designed to help individuals communicate their knowledge, experience, and contributions in ways that are both technically accurate and meaningful to human readers.

HCOS recognizes that professional documents are more than hiring artifacts—they are opportunities to communicate competence, contribution, integrity, and the value a person brings to the systems in which they work.

---

# Repository Purpose

This repository develops practical career resources that align with HCOS principles while remaining useful in real-world hiring environments.

Resources are designed to:

- Preserve truthfulness
- Improve professional communication
- Balance ATS optimization with human readability
- Recognize contributions rather than simply listing tasks
- Promote evidence-based improvement
- Support continuous learning

# Validation

Each major tool includes a validation folder.

Validation supports continuous improvement through:

- user feedback
- recruiter feedback
- hiring manager review
- ATS testing
- subject matter expert review
- literature review
- implementation experience

HCOS views validation as an opportunity to learn rather than an attempt to prove perfection.

# Design Principles

Resources within this repository should:

- remain truthful
- avoid exaggeration
- preserve human dignity
- communicate clearly
- remain evidence informed
- recognize systems thinking
- support professional growth
- be practical for real-world use

Every resource should improve both technical communication and human understanding.

# Guiding Principle

Professional documents should never reduce people to lists of tasks.

They should communicate competence, contribution, integrity, and the positive impact an individual has on the people, organizations, and systems they serve.

HCOS seeks to help professionals communicate both what they do and why their work matters.
